# 나두원피스

동블루에서 에그헤드까지, 원피스를 아크 단위로 읽는 비공식 가이드입니다.

회차마다 따라가지 않습니다. 사가와 아크, 인물, 관계, 짧은 명대사, 악마의 열매, 현상금, 세계의 구조를 한국어로 정리합니다. 엘바프 이후는 적지 않습니다.

팬이 만든 비공식 정리 사이트입니다. ONE PIECE의 저작권은 원작자(오다 에이치로)와 슈에이샤, 토에이 애니메이션에 있습니다.

## 실행

```bash
npm install
npm run dev
```

정적 빌드 확인:

```bash
npm run build
```

배포는 Vercel의 Next.js 기본 설정으로 충분합니다. 별도 환경 변수는 필요 없습니다. 사이트 주소의 기본값은 `https://nadoo-onepiece.vercel.app` 입니다.
